# Yapıştırmalı Plise Perde

Next.js ile geliştirilmiş modern yapıştırmalı plise perde web sitesi.

## Özellikler

- Delmeden montaj sistemi
- Özel ölçü üretim
- Çeşitli kumaş seçenekleri
- Responsive tasarım
- TypeScript desteği

## Kurulum

```bash
npm install
npm run dev
```

## Build

```bash
npm run build
npm start
```
